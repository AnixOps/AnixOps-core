# 内网组网模块：内核需求

状态：需求已确认（2026-11-25），协议规范见 PR #289，骨干链路接口见 PR #291，实现进行中。
本页只列内核负责的需求；客户端界面、Agent、面板与私有构建各自在对应仓库提需求。编号沿用项目需求表（R1–R35）。

## 范围

内网组网模块与团队现有组网程序的节点直接互通，只用于内网之间通讯，放在内核中供全部平台使用。

## 内核负责的需求

| 编号 | 需求 |
|---|---|
| R1 | 与现有组网节点互通；兼容目标版本由协议规范给出。 |
| R2、R30 | 加密模式按网络统一，同一网络内全部节点使用同一模式，不逐连接协商。我方地区网络强制前向保密（安全模式）；默认模式只用于迁移期桥接节点连接旧网络的实例。 |
| R3 | 首批传输：TCP 与 UDP。 |
| R4 | macOS、iOS、Windows、Linux、Android 使用同一实现；无 Agent 部署另含 OpenWrt（R32）。 |
| R5 | 只用于内网：流量只进入虚拟网段与已接受的通告子网，不作为公网出口。 |
| R7 | 默认选路与现有行为一致：延迟最低或跳数最少。 |
| R8 | 进阶：按目标节点或目标子网指定途经节点（如 A 经 C 到 B）。途经节点均为我方节点时严格按路径转发；途经现有程序节点时只保证第一跳。 |
| R9 | 途经节点不可达时自动回落默认路由，并报告不可达的节点。 |
| R10 | 桌面与服务器节点为完整节点（可中转、可通告子网）；iOS、Android 只作接入端。 |
| R11 | 不实现本机或远程管理端口，不接入远程配置服务器；配置与状态只经内核现有控制接口。节点之间的控制消息照常实现。 |
| R12（内核部分） | 启动前检查端口占用、虚拟网卡与路由冲突、同一节点身份已在线；有冲突拒绝启动并返回原因。 |
| R14 | 关闭加密的网络默认拒绝加入，显式选择后才以「未加密」状态运行。 |
| R16 | 状态接口按对端给出通告子网、到达路径（直连或中转跳数）、延迟，并标出重叠网段。 |
| R17 | 子网通告只接受私有地址范围（10/8、172.16/12、192.168/16、100.64/10、fc00::/7）；公网网段不安装路由并告警。完整节点可发现本机局域网网段，作为待通告建议，确认后才通告。 |
| R18、R19 | 按地区分区：每个地区是独立网络，边界节点同时加入多个网络并互相通告网段；地区之间全互联，持续测量延迟与丢包，变差时改经第三地区中转，恢复后切回；每个地区至少两台边界节点。 |
| R21、R25 | 宿主组：同一物理机上的虚拟机由一到两台网关代表入网，网关通告组地址段（地区虚拟网段之外）；组内成员随网关路径。 |
| R22（开源部分） | 地区之间的链路经「骨干链路」接口接入（PR #291）；路由、代价与绕行由组网模块决定，链路的加密与承载由链路实现负责。开源构建不包含专线实现。 |
| R28 | 内网域名：`主机名.地区.mesh.internal`，同地区可只写主机名；在内核 DNS 模块按后缀本机应答（含反向解析），不发网络查询；重名时返回全部地址并标出。 |
| R29 | 基础节点使用固定地址；个人设备地址由面板分配并按设备身份保持不变。发现地址冲突时固定地址节点只告警不让出；发现自行分配地址的现有程序节点时告警「地址未受管」。 |
| R32、R35（OpenWrt） | OpenWrt 软件包只含独立组网程序（不带代理、MITM、脚本等其他功能），musl 静态构建，注册 procd 服务，配置使用 OpenWrt 标准 UCI；体积以 16 MB 闪存路由器可安装为准。另提供 LuCI 网页插件：显示成员、子网、路径与延迟，可填入入网凭据、选择要通告的局域网网段；复杂设置由面板下发，插件以查看为主。插件读取状态不新增网络监听端口（R11）。 |

## 结论、成果与审计

- 每条需求都须有结论（采纳、暂缓或不采纳及理由）、成果（交付它的 PR 或文件）和审计。项目需求表按条目跟踪这三项。
- 内部审计由不参与实现的独立评审完成，以需求原文为验收标准逐项核对成果，并记录结论与日期。规范与实现分别审计。
- 每完成一个功能版本，另行安排第三方审计；第三方审计发现的问题在随后的小版本中修复。内部审计照常进行，不以第三方审计替代。

| 需求 | 结论 | 成果 | 审计 |
|---|---|---|---|
| R28 N-7（0.3.1） | 采纳：本地区没有可应答记录时，同一网络内合并多个地区的短名应标重名。 | 嵌入式引擎和独立节点共用的名字表（`crates/outbound-mesh/src/dns/mod.rs`）及 DNS 与快照回归。 | 主线 #439 已独立复审。候选验收见 [人工介入记录](manual-intervention.md#当前待处理)。 |

## 不在内核内的部分

- 客户端界面：anixops-net。
- 接管与导入、无 Agent 安装器、只读上报：Agent 仓库。
- 地区定义、地址分配、入网凭据：面板仓库。
- 专线骨干链路的实现：私有构建。
